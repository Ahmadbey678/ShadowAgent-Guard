ShadowAgent Guard

Your AI coding agent obeys files in the repo. Attackers can write those files.

One pull request can slip in a hallucinated package, an invisible instruction in AGENTS.md, an auto-approved shell tool, or a deleted test. ShadowAgent Guard diffs every PR, grades it A to F and blocks the merge before an agent or a developer runs any of it.
